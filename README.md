# Thermal-Induced-Propagation-Delay
FPGA ring-oscillator thermometry: measuring how temperature stretches gate propagation delay, via a 64-RO / 64-heater characterization array on the Opal Kelly XEM7310 (Artix-7).   On-chip temperature sensing from propagation delay — ring oscillators slow down as the die heats up; this maps and ranks 64 of them against 64 heaters.
